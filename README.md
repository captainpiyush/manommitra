# SWARTHIKA — PS093 SIH 2026 Demo Prototype

React + Tailwind CSS (Vite) frontend prototype for Smart India Hackathon PS093.

## Demo journey
Welcome → Language → Safe start → Complaint → Details → Screening → Risk → Support → Submit → Track

## Demo behavior
- All data is local/mock data.
- AI processing is simulated with progress/loading states.
- SVI is a screening/triage aid, not a medical diagnosis.
- Emergency actions are simulations and do not contact real authorities.
- Human review remains the decision gate.

## Run
```bash
npm install
npm run dev
```
